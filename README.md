# Node.js Backend Project — Short Notes

→ **Install Node.js** → run `npm init` → creates `package.json`.

→ **Project folders:**
`controllers/` → business/request logic
`routes/` → API routes
`models/` → MongoDB schemas
`middlewares/` → request processing/authentication
`utils/` → reusable functions
`services/` → business logic/external services

→ **Libraries:**

→ **Nodemon** → watches files → automatically restarts server.

→ **Express** → create/run HTTP server + routes + middleware.

→ **dotenv** → loads `.env` variables into `process.env`.

→ **Mongoose** → connect Node.js with MongoDB + schemas/models.

→ **CORS** → allows frontend to access backend from another origin.

→ **cookie-parser** → reads cookies from incoming requests → `req.cookies`.

→ **bcrypt** → hash passwords + compare passwords.

→ **jsonwebtoken (JWT)** → create/verify access & refresh tokens.

→ **Multer** → handle `multipart/form-data` → file uploads.

---

→ **app.js** → creates Express app → middleware → routes.

→ **index.js** → database connection + starts server.

→ **Express middleware order:**
`cors → json → urlencoded → cookieParser → routes`

→ `express.json({limit: "20kb"})` → parse JSON request body + limit size.

→ `express.urlencoded({extended: true})` → parse URL-encoded form data.

→ **Router** → separates routes from `app.js` → mounted using `app.use()`.

→ **Route params:** `req.params`

→ **Query params:** `req.query`

→ **Request body:** `req.body`

→ **Response:** `res.status().json()`

---

→ **Utility functions:**
`ApiResponse` → standard success response
`ApiError` → standard error
`asyncHandler` → handles async controller errors
`database.js` → MongoDB connection
`cloudinary.js` → Cloudinary configuration/upload

→ **asyncHandler** → catches rejected promises → passes error to Express.

---

→ **User Model** → define user schema using Mongoose.

→ **Mongoose methods** → add functions to user document.

→ **`this` in Mongoose methods** → use normal `function`, not arrow function.

→ **Password hashing:**
`pre("save")` → check `isModified("password")` → `bcrypt.hash()` → store hash.

→ Always use:

```js
this.password = await bcrypt.hash(this.password, 10);
```

→ **Password checking:**

```js
bcrypt.compare(password, this.password)
```

→ Never store plain-text passwords.

---

→ **Cloudinary** → cloud storage for images/files.

→ **Multer middleware** → receives uploaded files → provides `req.file` / `req.files`.

→ Upload file → Multer → local path → Cloudinary → save `secure_url` in MongoDB.

# Authentication

→ **Register:**
Validate input → check existing user → upload images → create user → password automatically hashed by pre-save hook.

→ **Login:**
Find user → compare password → generate access token + refresh token.

→ **JWT:**
`jwt.sign()` → create token
`jwt.verify()` → verify token + expiration

→ **Access Token** → short-lived → e.g. `15m` → used for authenticated API requests.

→ **Refresh Token** → long-lived → e.g. `7d` → used to generate a new access token.

→ `expiresIn: "15m"` → use this for JWT expiry.

→ `exp` → automatically generated by JWT → Unix timestamp in seconds.

→ **Never use** `exp: "15m"` → `exp` must be a number.

→ Access token expires → server rejects it → refresh token → generate new access token.

→ **`verifyJWT` middleware** → checks access token → finds user → stores user in `req.user`.

→ Access token can be sent as:

```text
Authorization: Bearer <accessToken>
```

→ Read token:

```js
req.header("Authorization")?.replace("Bearer ", "")
```

→ Verify:

```js
jwt.verify(accessToken, process.env.ACCESS_TOKEN_SECRET)
```

→ Find authenticated user:

```js
User.findById(decodedToken._id)
```

→ Attach user:

```js
req.user = user;
```

→ Protected route:

```js
router.post("/logout", verifyJWT, logoutUser);
```

---

# Logout

→ Get authenticated user from `req.user`.

→ Find user using `_id`.

→ Set:

```js
user.refreshToken = "";
```

→ Save user.

→ Clear refresh-token cookie:

```js
.clearCookie("refreshToken")
```

→ Return response using:

```js
res.status(200).json(new ApiResponse(...))
```

# Important Concepts Learned

→ **`await`** → waits for Promise result.

→ `User.findById()` without `await` → returns Mongoose Query.

→ `User.findById()` with `await` → returns User document.

→ **Normal function vs arrow:** Mongoose methods needing `this` → normal function.

→ **Cookie vs Authorization header:**
Cookie → `req.cookies`
Header → `req.header("Authorization")`

→ **HttpOnly cookie** → JavaScript cannot directly access the cookie.

→ **Environment variables** → secrets/configuration stored in `.env`.

→ **Never expose JWT secrets** in code or GitHub.

→ **Login → Access Token + Refresh Token → verifyJWT → protected routes → refresh token → new access token → logout.**
